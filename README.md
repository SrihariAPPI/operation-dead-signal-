# Operation Dead Signal

Cyberpunk tactical FPS built with three.js (r128). Single static page, no build step.
Gameathon 8.0 entry.

## Play
Open `index.html` through any static server (pointer lock and audio need http, not file://):

    npx serve .

## Controls
WASD move, Shift sprint, Space jump, Ctrl/C crouch, Mouse look + fire, R reload, E hack, B bloom, V reflections, Esc pause.

## Deploy
Vercel: import the GitHub repo, Framework Preset "Other", no build command, output directory left empty.
